# docs/architecture/ —— 模块架构文档集

**状态：现行。改动结构（移动/新增/删除类、调整包归属）前必读。**

本目录是模块化重构（2026-10-05 起）的**目标架构 + 现状契约**文档集。它回答三个问题：

1. **模块边界在哪**：每个包的职责、允许的依赖方向、当前违反项（见 `00-module-map.md`）。
2. **每台机器迁移时不能动什么**：存档契约（槽序、NBT 键、注册名、战利品表）逐台留档（见 `legacy/`）。
3. **怎么拆才安全**：巨型类的伴生类设计、公用工具的去留（见 `02`–`05`）。

## 硬约束（全目录通用）

- **不改包名 / 注册名 / lang 键 / NBT 键名**，不动 `mekck.refmap.json` 与 mixin 目标——都是旧存档契约。
- 本仓约 46 条**源码形态护栏**读源文本做结构断言；移动类会成批变红。处置只有三类：改代码 / 改判据落点 / 收缩登记表**并注释 `N → N-1 + 原因`**。**禁止为变绿而放宽判据或缩小扫描面。**
- 新增或改动源码形态断言**必须先做变异测试**（干净树绿 → 注入缺陷红）。
- 反射按名取用的成员永不重命名（见 `03-ae2.md`）。
