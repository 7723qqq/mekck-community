# 常见问题

## 机器为什么不动？

1. 检查电力（FE/t 是否足够）
2. 检查输入物品是否被机器接受（对照 JEI）
3. 检查红石模式（高电平/低电平/脉冲）
4. 检查产物格是否满

## 网络拉料没反应？

* 确认装了 AE2 且机器已连上 ME 网络（旁边有接口/线缆）
* 确认输入槽有空位

## 工厂怎么升级？

工厂共 **12 个等级**：

基础 → 高级 → 精英 → 终极 → 绝对 → 至尊 → 寰宇支配 → 悖论无限 → 烈焰炽焱 → 晶钛矩阵 → 星云塑造 → 奇点创世

**大多数工厂**：手持对应等级的**工厂安装器右键**即可升级（高工厂安装器可替代低等级）。此外还有两种等效方式：

* 无尽乐事对应等级的**刀**（与安装器等效）
* 无尽贪婪的**无尽升级组件**——视为奇点创世级安装器，每次使用扣 1 点耐久而非消耗

**例外：切菜工厂与烹饪工厂不接受工厂安装器**（Mekanism 的 4 种、扩展的 4 种、MekCK 自有的 3 种、以及无尽乐事的刀**全都不行**），
这两台机器只能**逐级合成**升级 —— 每一级的具体配方**在游戏里查 JEI / 配方书**即可，本指南不再重复列配方。

> ⚠️ **唯一例外是无尽贪婪的「无尽升级组件」**：它对这两台机器**在悖论无限及以下可用**，
> 但**晶钛矩阵及以上用不了**。其余工厂则任意等级（低于奇点创世）都能用无尽组件升。

升级会保留机器内的物品、能量、进度、侧边配置与红石模式，不会掉落。

## 联动模组没装？

不装联动模组时对应机器无配方可执行（GUI 仍可用）。

## 中央厨房装了模块却不工作？

1. 确认把**工厂或基础机器**放进了模块槽（普通升级不行）
2. 确认**同一系列只装了一个**（例如平均切段机与万能切菜机同属切割系列）
3. 默认**只在下单时加工**：需要在「下单」窗口选配方并下单，或给该模块开启自动加工
4. 检查存储区材料是否够、输出区是否已满

## 中央厨房为什么做不出汉堡？

它能自动展开合成链：只要缺少的中间产物**有对应系列模块**，就会先做中间产物再做成品（例如先切牛肉馅再烹饪）。
检查是否装了对应系列（如切菜工厂）。合成链最深 3 层，全部原料都能由存储区满足才接受订单，否则会直接告诉你缺什么。

## 中央厨房的「样品槽」是做什么的？

只有装入**三明治组装机**模块后才需要用到：放入一个手工做好的三明治，中央厨房就会照它的材料清单量产同款。
其它系列的加工不需要它。

## 三明治组装机放了样品却不出货？

1. 确认已安装 **Some Assembly Required**（未安装时机器不工作，物品提示会写明）
2. 确认材料区里有样品清单里的**每一种**材料
3. 材料需与样品**完全一致**（含 NBT）——带附魔或药水的材料也会精确匹配
4. 确认输出槽未满（三明治自身只能堆叠 16 个，机器会自动分批）

## 种植切配站不种东西？

* 需要安装 **mekmm（通用机械：更多机器）** 提供营养液
* 种子作催化剂不消耗，但必须有营养液
* 升级到烈焰炽焱 / 晶钛矩阵 / 星云塑造 / 奇点创世后营养液消耗大幅降低（-90% / -95% / -99% / -100%），且无需安装气体升级

## 急冻制冰机为什么不加工？

* 机身温度必须**低于 0 ℃** 才能加工，温度越低越快（0 ℃ 为 1 倍、绝对零度 30 倍）
* 界面内可开启控温并设定目标温度（默认 −273.15 ℃）
* 急冻制冰机**不支持速度升级**，速度完全由温度决定

## 机器会产热吗？会影响运行吗？

烹饪 / 烘焙 / 烧烤 / 炒制类机器运行时按消耗的电能产热，机身温度显示在界面中，可与相邻的通用机械热力设备互相传热。
**温度不影响这些机器的运行**，只影响急冻制冰机（它靠低温提高速度）。

## 装盘配方是哪来的？

本模组会**自动扫描**所有已安装模组的宴席方块，生成融合机配方：宴席方块 + 容器 ×（份数 − 方块合成已含的容器数）→ 碗装食物 ×份数。
例如烤鸡加三个碗可以得到四份碗装烤鸡。配方在启动与每次 /reload 时重建。

## 弹出功能会把原料弹出去吗？

不会。主动弹出只处理**产物**，原料不会被弹出。
种植切配站与种植切配工厂的气体弹出是关闭的。

## 怎么关闭某些自动功能？

配置文件位于 `config/mekck/mekck-common.toml`：
* `[planting] auto_generate_planting_recipes` —— 是否自动生成种植配方
* `[planting] print_planting_debug_to_chat` —— 是否在聊天栏输出生成调试信息
* `[plating] auto_generate_plating_recipes` —— 是否自动生成装盘配方
