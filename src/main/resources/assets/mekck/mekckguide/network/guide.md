# 关于本指南（GuideME）

本指南由 GuideME 提供，内容随模组一起分发，不需要额外下载。

## 怎么打开

* **手持任意 MekCK 机器按 G 键**：直接跳到该机器的页面（多台同系列机器进同一页）。
* **按 G 打开指南首页**：从目录里选页面浏览。
* 键位可在控制设置里修改。

## 怎么查配方

* **JEI**：摸清某个机器能做什么，最直接的办法是看 JEI 配方页右侧的**催化剂栏**——那里列出能执行该配方的机器。
* 中央厨房可以装入任意系列模块，因此它会出现在**所有**相关配方页的催化剂栏里。
* 机器方块物品的 **tooltip** 会写明它的用途与所需联动模组。

## 指南里能查到什么

* [[machines/overview.md|机器总览]]：全部机器一览与通用功能
* 每个机器系列一页：槽位、数值、升级、联动配方
* [[machines/temperature.md|温度系统]]：哪台机器产热、制冰机怎么控温
* [[machines/central_kitchen.md|中央厨房]]：模块、存储、下单与合成链
* [[machines/sandwich.md|三明治组装机]]：三明治联动
* [[network/network-pull.md|网络拉料]] 与 [[network/me-ordering.md|ME 终端下单]]：AE2 自动化
* [[faq.md|常见问题]]：机器不动、做出不东西时先看这里

## 提示

按 **Shift** 查看物品的详细信息（已储能、是否存有物品等），按详情键可看机器用途说明。
