# 坚果爆炒机

## 坚果爆炒机（mekck:nut_roaster）

一台机器两种用途：炒坚果，顺便把炒好的坚果当子弹。

### 炒制生产

* 榛子 → 炒榛子（`mekck:nut_roasting` 配方），约 33 tick/份（原版 100 tick 的 1/3）。
* 输入格只接受配方材料。
* 炒榛子可以吃：饥饿 2 / 饱和 1（生榛子只有 1 / 0.5）。

### 自动防御

* 产物格里留有炒榛子时，**每 20 tick（1 秒）启动一轮攻击**；一轮最多 **5 颗**，**逐 tick 依次射出**（同一目标排队、不同目标同 tick 齐射）。
* 炒榛子**无重力直线飞行**（速度 2 格/tick），命中造成 **40 点火焰伤害**后消失；命中方块也会消失。
* 飞行距离达到设定射程后自动移除。
* 每轮**最多发射 5 颗**：按目标血量决定发数（血量 < x×40 的目标最多 x 颗，x = ⌊血量/40⌋+1），多个目标按远近依次分配。
* 逐 tick 发射（间隔 1 tick）。炒榛子可以穿过自己出生的爆炒机。

### 索敌与配置

* 目标类型（敌对 / 全部 / 动物）与半径（下限 4、上限 256）在界面内可调。
* 敌对名单支持自动扫描其它模组的敌对生物（配置 `auto_scan_hostile_entities`）。
* 攻击受红石控制。

### 弹药与数值

| 项 | 值 |
|---|---|
| 弹药 | 每发消耗产物格 1 个炒榛子；**装创造升级则无限弹药**，且**攻速变成每 tick 一轮** |
| 攻击耗电 | 不额外耗电 |
| 加工耗电 | 20 FE/t |
| 能源容量 | 100,000 FE |
| 升级 | 速度 / 能量 / 创造 |

### 温度

运行时按消耗的电能产热，机身温度显示在界面中，并与相邻的通用机械热力设备双向传导（**温度不影响加工**）。
