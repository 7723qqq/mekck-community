# 巧克力大炮

攻防一体的甜点火炮：先做巧克力，再把巧克力变成炮弹。

## 费列罗生产

配方（`mekck:ferrero`）：

| 输入 | 位置 |
|---|---|
| 榛子 | 输入槽 |
| 巧克力 | extra 输入槽（参考通用机械融合机的 extra 槽） |
| 牛奶 | 流体罐 1，50 mb |
| 榛子可可酱 | 流体罐 2，50 mb |

* 两个流体罐可**互换**（奶 / 酱放哪个罐都能合成）。
* 桶放进流体槽会自动抽入，空桶留在槽内；管道也可直接注入。

### 巧克力标签

* 配方读取 `#mekck:mekck_chocolate` 标签。
* **游戏启动时会自动把所有注册名带 chocolate 的物品并入标签**——其它模组的巧克力无需配置即可使用。

## 自动炮台

* 每 **2 秒**消耗产物格中的费列罗发动一波攻击。
* 费列罗从目标**头顶 5 格**生成（伴随传送音效与粒子），以 **10 倍重力**砸下。
* 命中时播放爆炸音效与粒子（**不破坏地形**），对 **3×3×3** 范围内实体造成伤害。
* **处决判定**：目标生命值低于伤害值时直接死亡。
* 产物格留有费列罗才会开火（装创造升级则无限弹药）。
* 攻击同样受红石控制与索敌配置（目标类型 / 半径，同急冻制冰机）。

## 费列罗升级（5 槽链式安装）

安装顺序：**椰蓉 → 死神 → 脆心 → 霸王死神 → 超重力场**。

**直击/处决阈值伤害按「已装升级数」沿阶梯取值**（与具体哪几档无关）：0 档 **250** / 1 档 **500** / 2 档 **600** / 3 档 **700** / 4 档 **800** / 5 档 **1000**；阶梯后统一乘配置 `[chocolate_cannon] ferrero_damage_mult`（默认 1.0）。

| 升级 | 非伤害效果 |
|---|---|
| 椰蓉 | 纯增伤档（无额外机制） |
| 死神 | 每波发射 **2 枚**，弹药消耗变为每发 2 个；目标不足时集火最高血量 |
| 脆心 | 被命中的实体移除 **2 秒 AI** |
| 霸王死神 | 伤害范围扩大为 **7×7×7** |
| 超重力场 | 伤害类型从爆炸变为**铁砧**；被击杀的实体不播放死亡动画 |
