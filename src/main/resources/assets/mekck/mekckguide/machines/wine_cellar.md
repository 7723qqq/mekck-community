# 陈化窖（时间悖论产生器）

一台**独立容器方块**：把葡园酒香（vinery）里带年份的酒瓶放进去，**把瓶子的年份往过去推**，
从而在极短时间内「催陈」出高年份好酒。它不产出新物品、不改变酒的种类，只让同一瓶酒的陈年时间飞速增长。

## 结构

* 单方块，右键打开界面。**9 个储存格**，每格普通堆叠（上限 64）。
* 只吃**能量（FE）**，**不耗任何气体**；**不支持升级槽**。

## 玩法

1. 把带 `Year` 标签的酒瓶（vinery 的葡萄酒等）放进任意格。
2. 在界面顶部**敲数字**选倍速 `S`（`1×`–`50×`，默认 `1×`）。
3. 机器逐格把酒的年份往前推；界面上的**酒红→琥珀闪电弧**会随正在陈化的格数变密。

## 数值

| 项 | 值 |
|---|---|
| 耗电 | `FE/t = 62.5 × 数量 × S`（校准点：64 瓶 @ 10× = 40,000 FE/t） |
| 每酒年耗时 | `576,000 ÷ S` tick（1× 时 = 8 现实小时推 1 酒年） |
| 能源缓冲 | 4 亿 FE |
| 供能不足 | 按「实抽 / 应抽」比例自动降速，不会硬扣 |

## 行为细则

* **逐格判定**：某格酒已达 vinery 效果上限（年份推到地板）⇒ 自动**停该格运行并停该格耗能**，不白烧电。
* **不装 / 读不到 vinery**：该格 fail-safe——既不催陈也不计费。
* **年份靠 NBT 天然不堆叠**：不同年份的酒 tag 不同，永远各占各格，不会串味混堆。

## 提示

它是给「酒窖党」的开挂器——想批量囤高年份酒，接上电网、拉满倍速即可；但注意 `50×` 满架时耗电相当可观。
