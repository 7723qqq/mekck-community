# 生物反应堆

本模组的**发电机器**：把食物与有机物变成电力。

## 结构

* **2×2×3 多方块**（主方块 + 11 个绑定方块）。
* 右键主方块或任意绑定方块都能打开界面。

## 两条产电路径

### 路径一：食物 → 有机物流体 → 电

把作物、肉类、合成食品等丢进 16 个输入槽，按规则换算成**有机物流体**（`mekck:organic_matter`）。
换算优先级：**配置文件 > Mekanism 粉碎→生物燃料 > 食物营养**（每饥饿点 = 200 mb）。

### 路径二：直接输入燃料流体 → 电

| 燃料流体 | 发电量 |
|---|---|
| 有机物流体 `mekck:organic_matter`（物品转化） | 350 FE/mb |
| 肉汤 `industrialforegoing:meat` | 8,000 FE/mb |
| 营养糊 `mekanism:nutritional_paste` | 1,400 FE/mb |

## 发电与输出

| 项 | 值 |
|---|---|
| 最大发电 | 8,000 FE/t |
| 主动推送 | 14,000 FE/t（推送到结构外表面的相邻机器 / 线缆） |
| 流体容量 | 480,000 mb |
| 能源缓冲 | 100,000 FE |

* **能源槽仅作输入**：放入能量立方 / 红石可补充机器储能；发电量直接送往线缆，不会反向充回槽内物品。
* **液体储罐槽**：界面流体条旁有一个专门格子，放入含水 / 含燃料的桶或液体储罐会自动把其中**能发电的燃料流体**（有机物流体 / 肉汤 / 营养糊）抽进流体格；水等非燃料流体不会被抽取。
* **JEI 可查**：每种可转化物品都会列出「X mb / 个」，方便规划投喂。

## 提示

它把你的食物储备变成一张持续产电的「生物电池」，是后期大工厂的电力兜底。
