# 机器分类索引

通用机械的机器按用途分成**六类**，逐类见对应页面。

## 一、物品加工

| 机器 | 干什么 | 详见 |
|---|---|---|
| 富集仓 | 矿石 → 粉（2×） | [[machines/ore_processing.md|矿石加工机器速查]] |
| 粉碎机 | 团块 → 脏粉、锭 → 粉 | 同上 |
| 电力熔炼炉 | 粉 → 锭（比熔炉快） | 同上 |
| 冶金灌注机 | 灌注强化材料 | 同上 |
| 融合机 | 把粗矿压回矿石 | 同上 |
| 精密锯木机 | 木材 → 木板 / 锯屑 | 同上 |

## 二、化学系

化学溶解室、化学清洗机、化学结晶器、化学压射室、提纯仓、化学氧化机、化学灌注器、加压反应室、回旋式气液转换机、电解分离器、热力蒸馏。
见 [[machines/chemical.md|化学系与气体产线]]。

## 三、工厂（并行版）

上面这些机器大多有**工厂版本**：9 类 × 4 级 = **36 个方块**。
见 [[machines/factories.md|工厂与并行处理]]。

## 四、物流与储能

通用线缆、机械管道、加压管道、物流管道、物流分类机、热导线缆、量子传送装置、QIO。
见 [[machines/logistics.md|管道、线缆与物流]]。

## 五、能量

能量立方（4 级）、感应矩阵（多方块）、发电设备（在**通用机械发电机**模组）。
见 [[basics/energy.md|能量与发电]]。

## 六、其它

数字型采矿机、电动泵、充电台、传送机、私人箱子、安全设置台、改造站等。

另见 [[machines/overview.md|机器与配方总览]]（配方类型 → 机器的完整对照表）。
