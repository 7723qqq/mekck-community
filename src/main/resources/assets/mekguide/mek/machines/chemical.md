# 化学系与气体产线

> 数据取自 `Mekanism-1.20.1-10.4.16.80.jar` 的配方 JSON（`separator` / `chemical_infusing` / `oxidizing` / `reaction` / `rotary` / `evaporating`），单位与数量逐条核对。

## 一、四套资源别混淆

| 资源 | 存放 | 传输 | 例子 |
|---|---|---|---|
| 物品 | 槽位/箱子 | 机械管道 | 矿石、粉、锭 |
| 流体 | 流体罐 | 加压管道 | 水、盐水、乙烯、液化氢 |
| 气体 | 化学品罐 | 加压管道 | 氧、氢、氯、氯化氢、硫酸 |
| 浆液 | 化学品罐 | 加压管道 | 脏铁浆液、洁净铁浆液 |

## 二、基础气体产线（可从零建起）

### 电解分离器 `separating`

| 输入 | 输出 |
|---|---|
| 水 **2 mB** | **氢 2 + 氧 1** |
| 盐水 **10 mB** | **钠 1 + 氯 1** |

⇒ **氧气与氢气**都来自水，**氯气**来自盐水 —— 这三者是整条化学链的地基。

### 化学氧化机 `oxidizing`（物品 → 气体）

| 输入 | 输出 |
|---|---|
| 盐粉（`forge:dusts/salt`）×1 | **盐水 15 mB** |
| 硫粉 ×1 | **二氧化硫 100 mB** |
| 锂粉 ×1 | **锂 100 mB** |

### 化学灌注器 `chemical_infusing`（气体 + 气体 → 气体）

| 输入 | 输出 |
|---|---|
| 氢 1 + 氯 1 | **氯化氢 1**（化学压射室用） |
| 氧 1 + 二氧化硫 2 | **三氧化硫 2** |
| 三氧化硫 1 + 水蒸气 1 | **硫酸 1**（化学溶解室用） |

⇒ **氯化氢与硫酸**的完整链路：

* **氯化氢**：盐 → 盐水 →（电解分离器）→ 氯；水 →（电解分离器）→ 氢；氯 + 氢 →（化学灌注器）→ 氯化氢；
* **硫酸**：硫 →（化学氧化机）→ 二氧化硫 →（+氧）→ 三氧化硫 →（**+ 水蒸气**）→ 硫酸。

> ⚠️ **别漏了「水蒸气」这一步** —— 它是个**气体**，由 **水经回旋式气液转换机**（`rotary`）得到：
> **水 ⇄ 水蒸气**（1:1）。建硫酸线时容易只顾着硫和氧，到灌注环节才发现缺这一路气。

### 气体槽直通 `gas_conversion`（**省事路线**）

通用机械的化学机器上有一个**气体槽**：把物品放进去，机器会直接把它转成对应的气体灌进自己的罐子，**不需要建整条化学线**。

| 投入 | 得到 |
|---|---|
| **盐粉** ×1 | **氯化氢 2 mB** |
| **硫粉** ×1 | **硫酸 2 mB** |
| 荧石 ×1 | **氧气 10 mB** |
| 锇锭 ×1 / 锇块 ×1 | 锇气体 200 / 1800 mB |

有气体槽的机器：**化学溶解室、化学灌注器、化学氧化机、电解分离器、回旋式气液转换机、化学压射室、提纯仓**（及其工厂）等。

> **划算吗？** 分东西看：
>
> * **硫酸**：直通只给 **2 mB/硫粉**，走完整硫线是 **100 mB/硫粉** —— **差 50 倍**，大批量还是要建线；
> * **氯化氢**：直通给 **2 mB/盐粉**，而「盐 → 盐水 → 电解 → 氯 + 氢」约 **1.5 mB/盐粉** —— 直通反而略高。
>
> 结论：**硫酸线值得建，氯化氢可以先靠气体槽顶一阵**。

### 热力蒸馏 `evaporating`（流体浓缩）

| 输入 | 输出 |
|---|---|
| 水 10 mB | **盐水 1 mB** |
| 盐水 10 mB | **锂 1 mB** |

### 回旋式气液转换机 `rotary`（气体 → 液化流体）

把**同一种**气体转成对应的液化流体，共 17 条：盐水、氯、乙烯、氢氟酸、氢……

## 三、塑料/基质产线（加压反应室 `reaction`）

| 输入 | 输出 | 时长 |
|---|---|---|
| 煤/木炭（`minecraft:coals`）×1 + 水 100 mB + 氧 100 | **氢 100** | 100 tick |
| 生物燃料 ×2 + 水 10 mB + 氢 100 | **乙烯 100** | 100 tick |
| 圆木 ×4 + 水 400 mB + 氧 400 | **氢 400** | 600 tick |
| 木粉 ×8 + 水 25 mB + 氧 25 | 氢 25 | 37 tick |

⇒ **乙烯**是塑料链的起点（再经回旋式气液转换机液化为液化乙烯，用于基质/塑料）。

## 四、建线建议顺序

1. **电解分离器 + 水**：先拿到氧与氢（氧气是 3× 净化链的必需品）；
2. **化学氧化机 + 盐**：盐水 → 电解分离器 → 氯；
3. **化学灌注器**：氯 + 氢 → **氯化氢**（5× 链化学压射室必需品）；
4. **硫线**：二氧化硫 → 三氧化硫 →（**+ 水蒸气**）→ **硫酸**（5× 链化学溶解室必需品）；
   **水蒸气**别忘：**水 →（回旋式气液转换机）→ 水蒸气**（1:1）；
5. 之后才轮到锇/铀/裂变等更深的链路。

## 五、容易踩的坑

1. **氧气 ≠ 空气**：氧气只能从水电解或氧化机获得；
2. **氯化氢/硫酸是气体**，要占化学品罐与加压管道，不是流体罐；
3. **回旋式气液转换机只做"气体 → 同种液化流体"**，不做化学反应；化学反应在加压反应室；
4. 浆液（脏/洁净）与气体共用化学品罐，注意分配容量。
