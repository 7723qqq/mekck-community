# 矿石加工机器速查

> 用法与用量取自 `Mekanism-1.20.1-10.4.16.80.jar` 配方 JSON；原料允许**矿石 / 粗矿 / 粗矿块 / 碎片 / 晶体**等多种起点。

## 一、物品类机器

| 机器 | 配方类型 | 作用 | 典型配方（铁） |
|---|---|---|---|
| **富集仓** | `enriching` | 矿石 → 粉（2×）；脏粉 → 粉；矿石/粗矿也可直接富集 | 矿石 ×1 → 铁粉 ×2；粗矿 ×3 → 粉 ×4；粗矿块 ×1 → 粉 ×12 |
| **粉碎机** | `crushing` | 团块 → 脏粉；金属锭 → 粉 | 团块 ×1 → 脏铁粉 ×1；铁锭 ×1 → 铁粉 ×1 |
| **提纯仓** | `purifying` | **+氧气**：矿石 → 团块（3×）；碎片 → 团块 | 矿石 ×1 + 氧气 1 → 团块 ×3；碎片 ×1 + 氧气 1 → 团块 ×1 |
| **化学压射室** | `injecting` | **+氯化氢**：晶体/矿石 → 碎片 | 晶体 ×1 + 氯化氢 1 → 碎片 ×1；矿石 ×1 + 氯化氢 1 → 碎片 ×4 |
| **冶金灌注机** | `metallurgic_infusing` | **+灌注物**：金属锭 → 强化/富集材料 | 铁锭 ×1 + 碳 10 → 富集铁 ×1 |
| **融合机** | `combining` | 粗矿 + 圆石 → 矿石（把粗矿压回矿石）；**多数金属 ×8，铜要 ×20** | 粗铁 ×8 + 圆石 → 铁矿石 ×1 |
| **精密锯木机** | `sawing` | 木材 → 木板/锯屑（124 条，非金属链） | — |


## 二、化学系机器

| 机器 | 配方类型 | 作用 | 典型配方（铁） |
|---|---|---|---|
| **化学溶解室** | `dissolution` | **+硫酸**：矿石/粗矿 → 脏浆液 | 矿石 ×1 + 硫酸 1 → 脏浆液 1000 mB |
| **化学清洗机** | `washing` | **+水**：脏浆液 → 洁净浆液（**1:1 按单位换算**，不改变总量） | 脏浆液 → 洁净浆液 |
| **化学结晶器** | `crystallizing` | 洁净浆液 **200 mB** → 晶体 ×1 | 洁净铁浆液 200 mB → 铁晶体 ×1 |
| **化学灌注器** | `chemical_infusing` | 两种气体 → 一种气体（3 条） | — |
| **化学氧化机** | `oxidizing` | 物品/流体 → 气体（3 条） | — |
| **加压反应室** | `reaction` | 气体 + 气体 → 气体/流体（12 条，如 乙烯 → 液化乙烯需 `rotary`） | — |
| **回旋式气液转换机** | `rotary` | 气体 → 流体（17 条） | — |
| **电解分离器** | `separator` | 流体 → 气体（2 条） | — |
| **热力蒸馏** | `thermal_evaporation` / `evaporating` | 盐水 → 锂 等（3 + 2 条） | — |


## 三、按"手上有什么"选起点

| 手上有 | 直接进 | 结果 |
|---|---|---|
| 矿石 | 富集仓 | 粉 ×2（2×） |
| 矿石 | 提纯仓 + 氧气 | 团块 ×3（3×） |
| 矿石 | 化学溶解室 + 硫酸 → 洗涤 → 结晶 | 晶体 ×5（5× 起点） |
| 粗矿 | 富集仓 / 提纯仓 | 粉 ×4（3 粗矿）/ 团块 ×2 |
| 粗矿 | 融合机 + 圆石（**铜 ×20**，其余 ×8） | 还原成矿石（再走上面任一条） |
| 碎片 | 提纯仓 + 氧气 | 团块（可直接接 3× 链后半段） |
| 晶体 | 化学压射室 + 氯化氢 | 碎片 |
| 金属锭 | 粉碎机 | 粉（应急） |


## 四、容易踩的坑

1. **只有 7 种矿石金属走全链**（铜/金/铁/铅/锇/锡/铀）；钻石、红石、煤、青金石、石英等**只有富集/粉碎类**配方，别指望 5×；
2. **氧气/氯化氢/硫酸都是化学品**，需要先建立气体产线（电解水 → 氢/氧；盐水 → 氯 → 氯化氢；硫 → 硫酸），否则化学链一步都走不动；
3. **洗涤是 1:1 换算**，不增产，只是把浆液从"脏"变"洁净"；真正决定倍率的是**化学结晶器的 200 mB/晶体**与**化学溶解室的 1000 mB/矿石**。
