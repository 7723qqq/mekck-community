# 矿石与金属

> 数据来源：`Mekanism-1.20.1-10.4.16.80.jar`，`data/mekanism/recipes/processing/**`。
> **本页数量与用量均逐条取自配方 JSON 的 `count` / `amount` 字段**，非估算。

## 一、2× 链（富集仓）

| 输入 | 机器 | 输出 |
|---|---|---|
| 矿石 ×1 | 富集仓 `enriching` | **粉 ×2** |
| 粗矿 ×3 | 富集仓 | **粉 ×4** |
| 粗矿块 ×1 | 富集仓 | **粉 ×12** |
| 金属锭 ×1 | 粉碎机 `crushing` | 粉 ×1 |


⇒ **1 矿石 → 2 粉 → 2 锭**（粉经熔炉 200 tick / 高炉 100 tick 成锭）。

## 二、3× 链（提纯仓 + 粉碎机 + 富集仓）

| 输入 | 机器 | 输出 |
|---|---|---|
| 矿石 ×1 + **氧气 1** | 提纯仓 `purifying` | **团块 ×3** |
| 粗矿 ×1 + 氧气 1 | 提纯仓 | 团块 ×2 |
| 粗矿块 ×1 + 氧气 2 | 提纯仓 | 团块 ×18 |
| 团块 ×1 | 粉碎机 | 脏粉 ×1 |
| 脏粉 ×1 | 富集仓 | 粉 ×1 |


## 三、5× 链（化学系全链）

| 步骤 | 输入 | 机器 | 输出 |
|---|---|---|---|
| 溶解 | 矿石 ×1 + **硫酸 1** | 化学溶解室 `dissolution` | 脏浆液 **1000 mB** |
| 溶解 | 粗矿 **×3** + 硫酸 1 | 化学溶解室 | 脏浆液 **2000 mB** |
| 溶解 | 粗矿块 ×1 + 硫酸 2 | 化学溶解室 | 脏浆液 **6000 mB** |
| 洗涤 | 脏浆液 + 水 | 化学清洗机 `washing` | 洁净浆液 |
| 结晶 | 洁净浆液 **200 mB** | 化学结晶器 `crystallizing` | 晶体 ×1 |
| 注入 | 晶体 ×1 + **氯化氢 1** | 化学压射室 `injecting` | 碎片 ×1 |
| 注入 | 矿石 ×1 + 氯化氢 1 | 化学压射室 | 碎片 **×4** |
| 注入 | 粗矿 **×3** + 氯化氢 1 | 化学压射室 | 碎片 **×8** |
| 净化 | 碎片 ×1 + **氧气 1** | 提纯仓 | 团块 ×1 |
| 粉碎 → 富集 | 团块 → 脏粉 → 粉 | — | 1:1:1 |


**倍率来源**：1 矿石溶解出 **1000 mB** 脏浆液，每 **200 mB** 结晶 1 晶体 ⇒ **5 晶体** ⇒ 5 碎片 → 5 团块 → 5 粉 → **5 锭**。

## 四、哪种材料适用（本次批量核对结果）

**走 2×/3×/5× 全链的 7 种矿石金属**（数值完全同构，仅产物名不同）：
**铜、金、铁、铅、锇、锡、铀**

| 金属 | 富集 矿石→粉 | 净化 矿石→团块 | 注入 矿石→碎片 |
|---|---|---|---|
| 铜 / 金 / 铁 / 铅 / 锇 / 锡 / 铀 | **×2** | **×3**（+氧气 1） | **×4**（+氯化氢 1） |

**只有富集/粉碎类配方、不走化学链的材料**（`processing/<材料>/` 下没有 clump/shard/slurry 文件）：
钻石、绿宝石、石英、红石、煤、青金石、氟石、下界合金、钢、青铜、强化荧石、强化黑曜石。

## 五、便捷配方

| 配方 | 说明 |
|---|---|
| 粗矿 + 圆石 | 融合机 `combining` → **对应矿石**（`ore/from_raw`）；**铜要 ×20，其余 6 种 ×8** |
| 金属锭 + **碳 10** | 冶金灌注机 → 富集金属（强化材料链起点） |
| 碎片 ×1 + 氧气 1 | 提纯仓 → 团块（可直接从碎片起链） |


## 六、各金属浆液数值（全量核对）

| 金属 | 矿石 → 脏浆液 | 粗矿 → 脏浆液 | 粗矿块 → 脏浆液 |
|---|---:|---:|---:|
| copper | **1000 mB** | **2000 mB** | **6000 mB** |
| gold | **1000 mB** | **2000 mB** | **6000 mB** |
| iron | **1000 mB** | **2000 mB** | **6000 mB** |
| lead | **1000 mB** | **2000 mB** | **6000 mB** |
| osmium | **1000 mB** | **2000 mB** | **6000 mB** |
| tin | **1000 mB** | **2000 mB** | **6000 mB** |
| uranium | **1000 mB** | **2000 mB** | **6000 mB** |

> 7 种矿石金属在此表上**完全同构**。
>
> ⚠️ **注意投入数量**：溶解**矿石是 1 个、粗矿是 3 个、粗矿块是 1 块**——
> 表里给的是**每次配方的产出**，不是"每个原料"的产出。
> 所以真正的说法是：**3 个粗矿 → 2000 mB**、**1 块粗矿块 → 6000 mB**（只有粗矿块能"一块顶 30 个晶体"）。
> 同理，**富集/注入**的粗矿配方也都要 **3 个**粗矿（富集 3→4 粉、注入 3→8 碎片）。
> **化学清洗机**的配方是**按单位换算**（脏浆液 : 洁净浆液 = 1 : 1，配方文件里写作 1 mB 的比例），
> 因此洗涤不改变总量，只是把"脏"变"洁净"。
> 化学结晶器每 **200 mB** 洁净浆液产出 1 晶体 ⇒ 1 矿石 = **5 晶体 = 5 锭**（5× 的来源）。
