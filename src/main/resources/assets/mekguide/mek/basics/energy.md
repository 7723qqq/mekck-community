# 能量与发电

> 数据来源：`Mekanism-1.20.1-10.4.16.80.jar` 与 `MekanismGenerators-1.20.1-10.4.16.80.jar`，
> 数值逐项取自配置默认值（`UsageConfig` / `StorageConfig` / `GeneralConfig` / `GeneratorsConfig`）的字节码常量。

## 一、能量单位：J 与 FE

通用机械**内部用 J（焦耳）记账**，界面上可以按 **FE** 显示。

> **换算关系：1 FE = 2.5 J**，即 **1 J = 0.4 FE**。
>
> 依据：`GeneralConfig.feConversionRate` 的配置注释原文 ——
> *"Conversion multiplier from Forge Energy to Joules (FE * feConversionRate = Joules)"*，默认值 **2.5**。

**J → FE 就是除以 2.5**。本指南两张单位都给，方便直接对照线缆与管道的上限。

显示单位可以在配置里切换（J / FE / EU 三选一），**不影响实际数值**，只影响界面文字。

## 三、发电

**通用机械本体没有任何发电机** —— 全部发电设备都在 **通用机械发电机**（MekanismGenerators）里。

| 发电机 | 输出 | 说明 |
|---|---:|---|
| **热力发电机** | **200 J/t（80 FE/t）** | 每有一面贴着岩浆 **+30 J/t**（含自身被岩浆浸没）；在**下界等超热维度 +100 J/t**；每转移一份热量消耗 **10 mB** 岩浆 |
| **生物能发电机** | **350 J/t（140 FE/t）** | 烧生物燃料 |
| **太阳能发电机** | 峰值 **50 J/t（20 FE/t）** | 白天、见天 |
| **高级太阳能发电机** | 峰值 **300 J/t（120 FE/t）** | 白天、见天 |
| **风力发电机** | **60 ~ 480 J/t（24 ~ 192 FE/t）** | 随**高度**变化（Y=1 起算），部分维度被列入黑名单 |
| **燃气发电机** | 按气体能量密度 | 烧**氢**或**乙烯**，见下表 |
| **裂变反应堆** | 每 1 mB 燃料 = **1 000 000 J 热量** | 热量再经**工业蒸汽涡轮**转成电 |
| **聚变反应堆** | 每 1 mB 燃料 = **10 000 000 J** | 需要 D-T 燃料与激光预热 |
| **工业蒸汽涡轮** | 蒸汽最高 **10 J/mB** | 消化裂变堆的热量/蒸汽 |

### 燃料的能量密度

| 燃料 | 能量密度 |
|---|---:|
| **氢** | **200 J/mB**（= 80 FE/mB） |
| **乙烯** | **28 200 J/mB**（= 11 280 FE/mB） |
| **蒸汽** | 最高 **10 J/mB** |

> 乙烯的算法：`2 × bioGeneration × ethyleneDensityMultiplier + 氢密度`
> = 2 × 350 × 40 + 200 = **28 200 J/mB**。

### 发电链条

```
水 →（电解分离器）→ 氢 + 氧
生物燃料 →（加压反应室，+水+氢）→ 乙烯 →（燃气发电机）→ 电
裂变燃料 →（裂变反应堆）→ 热 →（工业蒸汽涡轮）→ 电
D-T 燃料 →（聚变反应堆）→ 电（直接）
```

## 五、配线建议

1. **先算总耗能**：把机器数量 × 单机 FE/t 加起来，再选线缆等级
   （基础线缆 3 200 FE/t、高级 51 200、精英 409 600、终极 3 276 800）；
2. **线缆等级 = 传输上限**，低于机器峰值会**卡住**整条线；
3. **能量立方当缓冲**，感应矩阵当**总仓库**；
4. 发电机建议**直接贴能量立方**，再统一往外送，避免线缆成为瓶颈。

另见 [[machines/logistics.md|管道、线缆与物流]]、[[machines/chemical.md|化学系与气体产线]]、[[machines/overview.md|机器与配方总览]]。
