# 侧面配置、升级与红石

> 数据来源：`Mekanism-1.20.1-10.4.16.80.jar`（`DataType` / `RelativeSide` / `RedstoneControl` / `Upgrade` 枚举与 `TileComponentUpgrade` 字节码）。

## 一、侧面配置（Side Config）

通用机械的机器**每个面都能单独配置**，而且是**按资源类型分开配置**的。

### 六個面

`FRONT`（正面）、`LEFT`、`RIGHT`、`BACK`、`TOP`、`BOTTOM`
—— 以**玩家放置机器时的朝向**为基准，不是世界坐标。

### 五种配置页

界面顶部有**传输类型切换按钮**，每种类型的侧面配置**互相独立、互不影响**。

⚠️ **页数不是固定的** —— 机器支持几种资源，就显示几页（源码里 GUI 按 `TileComponentConfig.getTransmissions()` 逐页生成）。
通用机械共 **8 种**传输类型，常见的对应关系：

| 配置页 | 管的是什么 | 对应的管道 |
|---|---|---|
| **能量** Energy | 电 | 通用线缆 |
| **流体** Fluid | 水、岩浆、乙烯等 | 机械管道 |
| **气体** Gas | 氧气、氢气、氯化氢、硫酸 | 加压管道 |
| **浆液** Slurry | 脏浆液 / 洁净浆液（矿石 5× 链用） | 加压管道 |
| **灌注物** Infusion | 碳、红石、钻石等（冶金灌注机用） | 加压管道 |
| **颜料** Pigment | 颜料（上色机 / 颜料混合器用） | 加压管道 |
| **物品** Item | 物品 | 物流管道 / 漏斗 |
| **热量** Heat | 热 | 热导线缆 |

> 所以像**化学溶解室**会多出「浆液」页、**冶金灌注机**会多出「灌注物」页 —— 机器用不到的类型不会显示。

> 每种类型的配置**互相独立**：**同一个面可以"上面进物品、下面出能量"**，只要在两个不同的配置页里分别设好。

### 每个面能设成什么（`DataType`）

| 取值 | 含义 |
|---|---|
| **无** NONE | 该面不参与这种资源的传输 |
| **输入** INPUT | 只进不出 |
| **输入 1 / 输入 2** INPUT_1 / INPUT_2 | 双输入机器（如融合机）分槽输入 |
| **输出** OUTPUT | 只出不进 |
| **输出 1 / 输出 2** OUTPUT_1 / OUTPUT_2 | 分槽输出 |
| **输入输出** INPUT_OUTPUT | 双向 |
| **能量** ENERGY | 该面专用于能量（可与其他类型共存） |
| **额外** EXTRA | 次要输入/输出面（部分机器用） |

### 机器会"主动伸手"

设成 **输入** 的面，机器会**主动从相邻容器抽取**；设成 **输出** 的面，机器会**主动往外弹**。
所以常见做法是：**输入面贴来源容器、输出面贴目标容器**，不用漏斗也能全自动。

## 二、升级（Upgrades）

升级不是可有可无的装饰 —— **除了少数专用件，绝大多数机器都靠它把产能拉满**。

### 七种升级

| 升级 | 官方描述 | 单机上限 | 谁能装 |
|---|---|:---:|---|
| **速度升级** Speed | 提高机器速度 | **8** | **所有机器** |
| **能量升级** Energy | **提高机器的能量效率与容量** | **8** | **所有机器** |
| **降噪升级** Muffling | 降低机器噪音 | **4** | **所有机器** |
| **气体升级** Gas | 提高用气机器的效率 | **8** | 提纯仓、化学压射室、化学溶解室（**仅这 3 台**） |
| **锚升级** Anchor | **保持机器所在区块加载** | **1** | 数字型采矿机、传送机、充电台、激光 / 激光增幅器 / 激光牵引光束、量子传送装置 |
| **过滤升级** Filter | 把重水从普通水里分离出来 | **1** | **电动泵**（仅此一台） |
| **造石机升级** Stone Generator | 按需生成石头 / 圆石 | **1** | **数字型采矿机**（仅此一台） |

> 描述逐条取自 jar 内 `upgrade.mekanism.<名>.description` 语言条目，上限取自 `mekanism/api/Upgrade` 的 `maxStack` 常量。
>
> 两个容易记错的点：**「能量升级」是效率 + 容量双提升**，不只是加大电池；**「锚升级」是区块加载**，不是防拆。

### 升级支持的默认规则

**所有机器出厂自带「速度 + 能量 + 消音」三件套**
（`Machine` 构造器统一注入 `AttributeUpgradeSupport(SPEED, ENERGY, MUFFLING)`，不需要逐台声明）。

在这份默认清单之上，个别机器会**改写**或**清空**它：

| 情况 | 机器 |
|---|---|
| 默认三件套 + **气体** | 提纯仓、化学压射室、化学溶解室 |
| 改写为其它组合 | 数字型采矿机（速度 / 能量 / **锚** / **石料生成**）、电动泵（速度 / 能量 / **过滤**）、公式装配器与流体填充机（速度 / 能量）、维度稳定锚（仅能量）、QIO 输入总线与输出总线（仅速度） |
| 只有**锚** | 传送机、充电台、激光系列、量子传送装置 |
| 只有**消音** | 物流分类机、安全设置台、改造站、反质子核合成器 |
| **完全没有升级槽** | **能量立方、箱柜、液体储罐、化学品储罐**（储能方块显式移除了升级支持）；太阳能中子活化器、电阻加热器、可控振源 |

> 一句话：**速度 / 能量 / 消音是通用件，几乎每台机器都能装**；
> **气体 / 锚 / 过滤 / 石料生成是专用件**，装到不支持的机器上会显示「不支持」。

### 怎么装

1. 打开机器界面，右下角是**升级槽**；
2. 把升级物品放进升级槽 —— **每个耗时 20 tick（1 秒）**，进度条走完才生效；
3. 装完后空升级物品会**退回旁边的升级输出槽**，不会消失；
4. 想拆就把升级**从输出槽拿走**（或者用配置器）。

> `TileComponentUpgrade.UPGRADE_TICKS_REQUIRED = 20`，一次装一个、逐件读条。

### 工厂的升级从哪来

工厂的升级清单**继承自对应的基础机器**（`Factory.setMachineData` 里的 `setFrom(..., AttributeUpgradeSupport)`）：

* 冶炼 / 富集 / 粉碎 / 压缩 / 化合 / 灌注 / 锯木工厂 → **速度 + 能量 + 消音**；
* 提纯工厂 / 压射工厂 → 额外带 **气体**。

工厂**自身的等级**不用升级物品，而是用**工厂安装器**，见下一节。

### 其它模组追加的升级

> 本指南只写**通用机械本体**。本整合包还装了 **通用机械：扩展**（Mekanism Extras），
> 它往同一套升级枚举里追加了 **堆叠升级**、**离子膜升级**、**创造升级** 三种；
> 其中**只有创造升级没有配方**（只能从创造模式取得），其余两种都能正常合成。
> 三种升级的效果与数值，见后续的《通用机械：扩展》指南。

## 三、工厂安装器（等级升级）

工厂不是靠速度升级变强，而是靠**工厂安装器**：

* 安装器分 **基础 / 高级 / 精英 / 终极** 四档；
* 拿在**主手**、**潜行右键**工厂方块，等级 **+1**；
* 取代关系：基础 → 高级 → 精英 → 终极（并行数 3 → 5 → 7 → 9）。

详见 [[machines/factories.md|工厂与并行处理]]。

## 四、红石控制

每台机器（以及部分管道）都有自己的红石模式，**四种**：

| 模式 | 行为 |
|---|---|
| **忽略** DISABLED | 完全不理会红石信号（默认） |
| **高** HIGH | **有**红石信号时工作 |
| **低** LOW | **无**红石信号时工作 |
| **脉冲** PULSE | 收到一次**上升沿**就做**一次**操作，然后停下等下一次 |

> 需要"来一次信号做一次"的场合（例如定量灌注）用**脉冲**。

## 五、配置器（Configurator）

**配置器**是通用机械的万能扳手 —— **先用滚轮选模式，再点方块**。

| 模式 | 作用 |
|---|---|
| **物品 / 流体 / 气体 / 灌注物 / 颜料 / 浆液 / 能量 / 热量**（共 8 种） | 选好资源类型后，**右键机器面**循环切换该面在这个类型下的配置 |
| **无** EMPTY | 把该面设成「无」 |
| **旋转** ROTATE | 旋转方块朝向 |
| **扳手** WRENCH | **拆下机器**（内部物品与数据随方块保留） |

另外：

* **右键管道** → 改变连接类型（正常 / 推 / 拉 / 无）；
* **对物流分类机用** → 切换它的**颜色**（**过滤要在分类机自己的界面里设**，不是用配置器）；
* 还有 **红石敏感度**、**重置电动泵 / 流体填充机计数** 等针对特定方块的操作。

## 六、常见疑问

**为什么机器不动？** 按顺序查四件事：**① 有没有电**（能量面配好没）、**② 红石模式**（是不是被"低"卡住了）、**③ 侧面配置**（输入面接上没有）、**④ 缺不缺气体/流体**。

**升级能拆下来吗？** 能，升级项随时可以取出，效果立即撤销。

**侧面配置会随机器搬走吗？** 会，用配置器（或精准采集）拆下的机器保留侧面配置与升级。
