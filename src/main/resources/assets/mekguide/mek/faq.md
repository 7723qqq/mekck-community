# 常见问题

## 机器为什么不动？

**先看机器界面** —— 通用机械的机器会在界面上**直接列出原因**，不用猜：

| 界面提示 | 意思 | 怎么办 |
|---|---|---|
| **- 没有匹配的配方或输入不足** | 输入槽里没有它能处理的物品，或数量不够 | 对照 JEI 确认这台机器收什么 |
| **- 能量不足以运行** | 电不够 | 检查线缆等级 / 发电机 |
| **- 能量不足以最高速度运行** | 电够但不满速 | 补电，或装能量升级 |
| **- 输出的空间不足** | 产物槽满了 | 接上输出面或腾空产物格 |
| **- 输出空间不足，内置缓存溢出** | 产物堆积到溢出 | 同上，尽快清空 |
| **- 输入不会产生输出** | 这个输入在这台机器上做不出东西 | 换机器或换配方 |

界面**没有**任何提示时，再依次查这几样：

1. **红石控制**：模式设成「低」而当前有信号，机器就是停的（见 [[guides/operations.md|侧面配置、升级与红石]]）；
2. **侧面配置**：输入面没接上来源、或输出面被堵；
3. **气体 / 流体**：提纯仓要氧气、化学压射室要氯化氢、化学溶解室要硫酸 —— 缺一样就跑不动；
4. **升级**：装进去的升级过期了？

## 工厂和普通机器有什么区别？

工厂是**同一台机器同时处理 N 份材料**（并行），不是把 N 台机器摆一排。

* **并行数**：基础 3 / 高级 5 / 精英 7 / 终极 9；
* **单次处理时间**：**200 tick，与基础机器相同**，也**不随等级变**；
* **额定耗能**：**等于对应基础机器的耗能，同样不随等级变** —— 但**每个正在运行的并行进程各耗一份**，满载时是 N 倍。

> 也就是说：**工厂不省电，省的是占地**。详见 [[machines/factories.md|工厂与并行处理]]。

## 物品 / 流体 / 气体 / 浆液有什么区别？

四套独立资源：**物品**走槽位与机械管道；**流体**走流体罐与机械管道；**气体**与**浆液**都走化学品罐与**加压管道**。

> 别记反：**机械管道走流体**，**加压管道走气体/浆液**。详见 [[machines/logistics.md|管道、线缆与物流]]。

## 升级怎么装？

**升级物品**：打开机器界面，把升级放进升级槽，**每个读条 20 tick（1 秒）** 才生效；空升级物品会退回旁边的输出槽。

**工厂等级**是另一回事：用**工厂安装器**（拿在主手、潜行右键），不是「升级」。
安装器分基础 / 高级 / 精英 / 终极四档，高等级可替代低等级；
**只有本身有工厂版本的机器**才能用安装器升级 —— 它需要机器有对应的「可升级」属性。

各自支持哪些升级、装哪些机器，见 [[guides/operations.md|侧面配置、升级与红石]]。

## 矿石怎么做到 5 倍？

5× 走的是**化学系全链**，关键三步是 **化学溶解室 → 化学清洗机 → 化学结晶器**：

```
矿石 ×1 + 硫酸 1 →（化学溶解室）→ 脏浆液 1000 mB
脏浆液 →（化学清洗机，1:1）→ 洁净浆液
洁净浆液 200 mB →（化学结晶器）→ 晶体 ×1   ⇒ 1000 ÷ 200 = 5
```

> 注意 **「提纯仓」是 3× 那一步**（矿石 + 氧气 → 团块 ×3），**不是** 5× 的关键环节。
> 完整阶梯见 [[basics/multiplication.md|矿物处理倍率阶梯]]。

## 还有什么常见的坑？

* **只有 7 种矿石金属**（铜 / 金 / 铁 / 铅 / 锇 / 锡 / 铀）能走全链，钻石、红石、煤等只有富集/粉碎配方；
* **量子传送装置**要两端频率一致才能跨维度互传；
* **物流管道不会自己找目标**，必须配**物流分类机**；
