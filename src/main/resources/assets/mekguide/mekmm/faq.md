# 常见问题（FAQ）

## Q1：为什么工厂只有 4 档（基础 / 高级 / 精英 / 终极）？更高的量子、创造呢？

`FactoryTier` 枚举在本机 Mekanism（10.4.16.80）里**只有 4 个值**，mekmm 的工厂按 `4 档 × 15 种 = 60` 循环注册，与配方数完全吻合。
你在语言 / 模型文件里看到的 **超频 / 量子 / 量子凝态 / 超阈限 / 创造**这 5 档，是 **Evolved Mekanism（EM）联动**的产物——**没装 EM 时这些方块根本不存在**，本指南不写。详见 [[machines/factories.md|工厂]] §三。

## Q2：我想把工厂升到"绝对 / 至尊 / 寰宇支配 / 悖论无限"，去哪看？

那是 **通用机械：扩展（`mekanism_extras`）** 的高档工厂，配方只是把 `mekmm:ultimate_*_factory` 当前置材料，**产物本身是 `mekanism_extras:` 方块**。
请查《**通用机械：扩展**》指南 → [[meke:machines/factories.md|工厂：24 种 × 4 新等级]]。本指南不重复列这些方块。

## Q3：「化学品复制机」「无线传输站」为什么找不到 / 本指南不写？

它们是本 mod 的**死素材**——有模型 / 语言条目，但**没有方块注册、没有配方、没有战利品**，游戏内拿不到也用不了。
本 mod **实际可玩**的是：8 台耗能机 + 无线充电站 + 2 玩偶 + 9 大型多方块 + 8 储罐 + 60 工厂；
"化学品复制机 / 无线传输站"不在其中。

## Q4：为什么本指南不写合成表 / 配方材料？

指南只讲"这是什么、怎么串"，**一切具体配方（材料、产出、耗时、耗能）以 JEI 为准**。
复制机 / 工厂等还涉及跨模组联动，写死在书里容易过时。

## Q5：UU 物质到底怎么来？

**反物质 →（核合成，配空晶体）→ UU物质（物品）→（气体转换）→ UU物质（气体）→ 复制机消耗**。
每一步的具体比例看 JEI，详见 [[machines/replicator.md|复制机]] §二。

## Q6：种植老停，为什么？

种植站 / 种植工厂是"物品 + **营养液（`mekmm:nutrient_solution`）**"双输入，**营养液用光就停转**。
注意"**营养液**"和"**营养糊剂**（`nutritional_paste`）"是**两种不同气体**，别接错。详见 [[machines/planting.md|种植]]。

## Q7：环境气体收集器不产气？

它的收集前提是**机器上方不能有阻挡物**（官方 tooltip 明确 "机器上方有阻挡物 / 无阻挡物"）。把上方清空即可。详见 [[machines/replicator.md|复制机]] §四。

## Q8：G 键能跳到某页，但为什么没有"手持物品打开这本书"？

目前 mekmm 指南**只走 G 键跳页**（页面声明 `item_ids` 自动生效）。
"给每本指南配一个可手持打开的物品"是已登记的**保留项 R2**，需要额外做物品 / 注册 / 美术，尚未开工。

## Q9：大型多方块的结构尺寸书里怎么没有？

离线只能取到碰撞盒、取不到搭建模板，**结构尺寸待游戏内核实**后统一补，见 [[large_machines.md|大型多方块机器]] §四。
