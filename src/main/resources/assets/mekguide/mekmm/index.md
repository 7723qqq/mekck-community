# 通用机械：更多机器（mekmm）指南

本指南面向 **通用机械：更多机器**（More Machine，mod id `mekmm`），数值与命名全部取自 jar 内 `assets/mekmm/lang/zh_cn.json`（374 条）、字节码常量与配方 JSON。

## 它是什么

**通用机械：更多机器** 为通用机械本体追加了一整套**新机器 + 新工厂 + 9 台大型多方块 + 8 台化学品储罐**：

- **15 种工厂** × **4 个等级**（基础 / 高级 / 精英 / 终极）= **60 台工厂**；
- 与之配套的**基础单机**：数控三机（压模 / 车床 / 轧机）、回收机、种植站、复制机 / 流体复制机、环境气体收集器、无线充电站；
- **9 台大型多方块机器**（含数据提取档漏列的「大型燃气发电机」）；
- **8 台化学品储罐**（中型 / 大型 各 4 档）。

## 从这里开始（新手路线）

1. 先接电、先跑通**本体**的富集 / 化学反应链（见《通用机械》指南）。
2. **回收机**几乎零门槛——把不要的**有配方**物品丢进去换**废料**，废料可再加工成**废料盒**（建筑材料）。见 [[machines/recycler.md|回收机]]。
3. 加工金属 → **数控三机**（`cnc_stamper` / `cnc_lathe` / `cnc_rolling_mill`），三种新配方类型。见 [[machines/cnc.md|数控三机]]。
4. 想要批量处理本体那 9 种化学反应 → 上**氧化 / 溶解 / 清洗 / 结晶 / 加压反应 / 离心 / 液化 / 颜料提取 / 上色**共 9 种工厂。见 [[machines/factories.md|工厂]]。
5. **复制机 / 流体复制机**是「UU 物质 → 无限复制物品 / 液体」的中期核心（⚠ 语言文件里的「化学品复制机」未注册、游戏内不存在）。见 [[machines/replicator.md|复制机]]。
6. 大型多方块（如大型热力发电机）留到后期；结构尺寸建议先游戏内验证。见 [[large_machines.md|大型机器]]。

## 前置

* **必须**：通用机械（Mekanism）10.4.x
* **可选**：**Evolved Mekanism**——未安装时，工厂只到**终极**；本指南只写**基础 / 高级 / 精英 / 终极**这 4 档（详见 [[faq.md|常见问题]]）。
