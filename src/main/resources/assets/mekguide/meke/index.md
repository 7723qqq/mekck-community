# 通用机械：扩展（Mekanism Extras）指南

本指南面向 **通用机械：扩展 1.5.0**，数值全部按 jar 内数据（配置默认值、字节码常量、配方 JSON）整理。

## 它是什么

**通用机械：扩展** 在通用机械本体的 **4 个等级之上再加 4 个等级**，并把几乎所有机器、储能、管道都补齐到新等级。

```
基础 → 高级 → 精英 → 终极   ← 通用机械本体
  → 绝对 → 至尊 → 寰宇支配 → 悖论无限   ← 本模组追加
```

## 前置

* **必须**：通用机械（Mekanism）10.4.16 以上
* **可选**：通用机械：发电机（提供发电）、**通用机械：更多机器**（mekmm）—— 本模组会为它的 15 种机器补上高等级版本（见 [[machines/factories.md|工厂]]）
* 与本模组 MekCK 的 12 级工厂体系**命名对应**（绝对 / 至尊 / 寰宇支配 / 悖论无限）
