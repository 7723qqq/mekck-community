# 硅岩（Naquadah）全链

> 数据来源：`data/mekanism_extras/recipes/processing/naquadah/**`，逐条取自配方 JSON 的 `count` / `amount` 字段。

**硅岩是本模组的核心新材料**，处理链**照搬通用机械本体那 7 种矿石金属的架构** ——
凡是会处理铁/铜/锇的产线，接上硅岩就能跑。

> ⚠️ **但数量不完全一样，照抄会错**：硅岩的**富集**是 **1 个粗矿 → 4 粉**
> （本体的铁/铜等是 **3 个粗矿 → 4 粉**）。其余步骤与本体的投入数量一致。
> 下面每张表都标了实际投入。

## 一、倍率阶梯（与本体一致）

| 目标 | 需要的机器 | 需要新增的化学品 | 每 1 块硅岩矿得到 |
|:---:|---|---|---|
| **1×** | 熔炉 / 高炉 | — | 1 锭 |
| **2×** | 富集仓 | — | 2 粉 → 2 锭 |
| **3×** | 提纯仓（+ 粉碎机、富集仓） | **氧气** | 3 团块 → 3 锭 |
| **4×** | 化学压射室（+ 上述） | **氯化氢** | 4 碎片 → 4 锭 |
| **5×** | 化学溶解室 + 化学清洗机 + 化学结晶器（+ 上述） | **硫酸** | 5 晶体 → 5 锭 |

## 二、逐条数值

### 富集（富集仓）

| 输入 | 输出 |
|---|---|
| 硅岩矿 ×1 | 硅岩粉 **×2** |
| 粗硅岩 **×1**（本体是 ×3） | 硅岩粉 **×4** |
| 粗硅岩块 ×1 | 硅岩粉 **×12** |
| 硅岩锭 ×1 |（粉碎机）硅岩粉 ×1 |

### 净化（提纯仓，消耗氧气）

| 输入 | 输出 |
|---|---|
| 矿石 ×1 + 氧气 | 团块 **×3** |
| 粗硅岩 ×1 + 氧气 | 团块 **×2** |
| 粗硅岩块 ×1 + 氧气 | 团块 **×18** |
| 碎片 ×1 + 氧气 | 团块 ×1 |

### 注入（化学压射室，消耗氯化氢）

| 输入 | 输出 |
|---|---|
| 矿石 ×1 + 氯化氢 | 碎片 **×4** |
| 粗硅岩 **×3** + 氯化氢 | 碎片 **×8** |
| 粗硅岩块 ×1 + 氯化氢 | 碎片 **×24** |
| 晶体 ×1 + 氯化氢 | 碎片 ×1 |

### 溶解 → 洗涤 → 结晶（5× 链）

| 步骤 | 输入 | 机器 | 输出 |
|---|---|---|---|
| 溶解 | 矿石 ×1 + 硫酸 | 化学溶解室 | 脏硅岩浆液 **1000 mB** |
| 溶解 | 粗硅岩 **×3** + 硫酸 | 化学溶解室 | 脏硅岩浆液 **2000 mB** |
| 溶解 | 粗硅岩块 ×1 + 硫酸 | 化学溶解室 | 脏硅岩浆液 **6000 mB** |
| 洗涤 | 脏浆液 | 化学清洗机 | 洁净浆液（**1:1**，不增产） |
| 结晶 | 洁净浆液 **200 mB** | 化学结晶器 | 晶体 ×1 |

⇒ **1000 ÷ 200 = 5 个晶体**，这就是 5× 的来源。

### 收尾

| 步骤 | 机器 | 比例 |
|---|---|---|
| 团块 → 脏粉 | 粉碎机 | 1 : 1 |
| 脏粉 → 粉 | 富集仓 | 1 : 1 |

## 三、便捷配方

| 配方 | 说明 |
|---|---|
| **末地硅岩矿** | 粗硅岩 ×8 + 圆石 →（**融合机**）→ 末地硅岩矿 ×1 |
| 粗硅岩块 ↔ 粗硅岩 | 1 块 = 9 个 |
| 硅岩块 ↔ 硅岩锭 | 1 块 = 9 锭 |
| 原版熔炉 / 高炉 | 矿石 / 粗硅岩 / 粉 → **硅岩锭**（不用建化学线也能起步） |

## 四、相关流体与气体

| 名称 | 说明 |
|---|---|
| **六氟化硅岩** `naquadah_hexafluoride` | 气体（有桶装版本） |
| **含钋溶液** `polonium_containing_solution` | 流体（有桶装版本） |
| **钋-208** `polonium-208` | 流体（有桶装版本），用于反应堆燃料链 |

## 五、容易踩的坑

1. **硅岩不是"新体系"** —— 它和铁走的是同一条链，别去另建一套产线；
2. **氧气 / 氯化氢 / 硫酸一个都不能少**：3× 要氧、4× 要氯化氢、5× 要硫酸，先建化学线再谈倍率；
3. **洗涤不增产**，只是把浆液从脏变洁净；决定倍率的是**溶解 1000 mB/矿石**与**结晶 200 mB/晶体**；
4. 手上只有粗硅岩时，**融合机 + 圆石**可以先把它还原成矿石，再走全链。
