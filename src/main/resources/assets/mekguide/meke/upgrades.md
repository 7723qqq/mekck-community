# 堆叠 / 离子膜 / 创造升级

> 数据来源：`MixinUpgrade` 字节码（本模组用 Mixin **向 `mekanism.api.Upgrade` 枚举追加**三个变体）
> 与 `ExtraUpgradeUtils`、语言条目、配方 JSON。

本模组往本体那套升级体系里**追加了三种升级**，它们和本体七种升级一起出现在机器的升级槽里。

## 一、三种升级

| 升级 | 官方描述 | 单机上限 |
|---|---|:---:|
| **堆叠升级** Stack | Increase the parallel number of work.（提高并行数） | **6** |
| **离子膜升级** Ionic Membrane | Ions can be filtered out from liquids.（从液体中滤出离子） | **1** |
| **创造升级** Creative | The machine does not consume energy and has no working time.（机器不耗能、无工作时长） | **1** |

> ⚠️ **创造升级没有配方**，只能从创造模式取得。**除了它，所有升级都有正规获取途径。**

## 二、堆叠升级（最重要的一种）

**效果**：并行数 = `2 ^ 安装数量`

| 安装数 | 并行倍率 |
|---:|---:|
| 1 | 2× |
| 2 | 4× |
| 3 | 8× |
| 4 | 16× |
| 5 | 32× |
| **6（上限）** | **64×** |

> 界面里显示为 `Parallel: %sx`。
> 和工厂的等级并行是**叠乘**关系 —— 悖论无限工厂（17 并行）再堆满堆叠升级 = **17 × 64 = 1088 份并行**。

## 三、离子膜升级

**效果**：让**电动泵**能从液体中**滤出离子**（把重水与普通水分离）。

* 上限 **1 个**，装多了没用；
* 是**电动泵专用** —— 装到别的机器上会显示「不支持」。

## 四、创造升级

**效果**：机器**不消耗能量**，且**没有工作时长**（瞬间完成）。

* 上限 **1 个**；
* **没有配方** —— 创造模式专属，正常生存拿不到；
* 拿到后装进任何支持升级的机器即可。

## 五、怎么装（与本体一致）

1. 打开机器界面，右下角是**升级槽**；
2. 放入升级物品 —— **每个耗时 20 tick（1 秒）**；
3. 空升级物品会**退回旁边的升级输出槽**；
4. 想拆就把它从输出槽拿走。

> 本体的七种升级（速度 / 能量 / 消音 / 气体 / 锚 / 过滤 / 石料生成）详解见《通用机械》指南的
> 「侧面配置、升级与红石」页。

## 六、容易踩的坑

1. **堆叠升级是乘方不是相加** —— 6 个是 64 倍，不是 12 倍；
2. **堆叠升级会让耗能同步暴涨**（每个并行进程各耗一份），配电网要先跟上；
3. **离子膜升级只对电动泵有效**；
4. **创造升级无配方**，别在 JEI 里找它。
